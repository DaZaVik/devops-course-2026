# Мой пет-проект

## Идея
Консольный планировщик учебных задач: сохранять практические работы,
сроки сдачи и статус выполнения, выводить ближайшие дедлайны.

## Стек
Python 3, SQLite, pytest. Позже — Docker и GitHub Actions.

## Цель
Научиться работать с GitHub Flow, хранить данные в SQLite,
проверять код тестами и запускать проверки в CI.

## Минимальная версия
- Добавить задачу с названием дисциплины и сроком сдачи.
- Показать список задач по сроку.
- Отметить задачу выполненной.

## Критерий готовности
Задача сохраняется после перезапуска, список упорядочен по сроку,
а выполненные задачи можно скрыть. Основные операции покрыты тестами.
