# Git в VS Code и терминале

## Три удобные возможности VS Code
1. Source Control показывает изменённые и подготовленные к коммиту файлы; легко проверить состав коммита.
2. Встроенный diff выделяет добавленные и удалённые строки рядом с исходным текстом. На hobby.md проверен раздел «Критерий готовности».
3. Граф коммитов и метки веток помогают видеть историю и исходящие изменения; коммит 212c142 создан кнопкой «Фиксация». Установлен GitLens для просмотра авторства строк.

## Что удобнее в терминале
Интерактивный rebase: команда `git rebase -i HEAD~3` явно задаёт диапазон и позволяет выбрать pick, squash и порядок коммитов. Такие операции удобно повторять по командам и использовать в скриптах.
